# 제품 썸네일 기준 재정립 및 12개 이미지 교체

사용자가 썸네일 선정 기준을 물어서 답했더니, 명시적 기준을 줬다: **단독컷**(제품 1개만),
**인물·신체 없음**, **다중 제품(번들/기획) 안 됨**, **텍스트 최소화**(가장 낮은 우선순위).
이 기준으로 기존 17개 실제 제품 썸네일을 전수 재검토했다.

## 감사 결과

17개 중 12개가 위반이었다:

- **COSRX 5개** — 대부분 기본 갤러리 순서(1~2번째)만 보고 넣었는데, 실제로는 클리닉 통계
  인포그래픽, 손+피부 클로즈업 "Before/After", "GLOBAL NO.1" 마케팅 문구, 심지어 제품이
  아예 안 보이는 임상시험 결과표였다.
- **Round Lab 클렌저·토너** — 클렌저용으로 쓴 이미지가 사실 "손바닥 위 거품"(용기 자체가
  안 보임) 사진이었고, **토너는 그 클렌저 사진을 그대로 복붙해서 쓰고 있었다** — 기준
  위반이기 전에 순수 데이터 버그.
- **Round Lab 크림** — 텍스처 스와치(크림 발림 사진)만 있고 용기가 안 보임.
- **올리브영 4개(구달·넘버즈인·조선미녀·아누아)** — 올리브영이 상세페이지 최상단에 쓰는
  "대표 이미지"가 사실 브랜드의 판매 프로모션 배너였다: 1+1 뱃지, 할인 문구, 수상 뱃지,
  기획 세트(본품+리필 2개), 심지어 **아누아는 제품을 든 모델의 얼굴·손이 나온 광고 사진**,
  **넘버즈인은 아이돌(NCT WISH) 포토카드 증정 문구까지 박힌 프로모션 배너**였다.

## 고친 방법

- **COSRX·Round Lab**: 각 상품의 Shopify `.json` 엔드포인트(`/products/{handle}.json`)로
  `images[].src`/`alt`를 한번에 가져와서, alt 텍스트 설명만으로 마케팅 이미지인지 걸러낸
  뒤 후보를 스크린샷으로 최종 확인 — 갤러리 전체를 하나씩 열어보는 것보다 훨씬 빨랐다.
- **올리브영 3개(구달·조선미녀·아누아)**: 같은 상세페이지 안에서 "대표 배너" 바로 다음
  이미지 번호(파일명 끝자리 +1)가 실제로는 깨끗한 단독 패키지샷이었다 — 배너와 패키지샷을
  같이 올려두는 패턴을 확인.
- **넘버즈인**: 올리브영에 등록된 리스팅 2개가 전부 프로모션 기획 상품이라 대체 이미지가
  없었다 — 대신 넘버즈인 브랜드 자사몰(numbuzin.com, Cafe24 기반)에서 직접 상품 페이지를
  찾아 단독컷을 가져왔다. 작은 원형 뱃지 텍스트("각질케어"/"화잘먹") 2개가 라벨에 인쇄돼
  있지만, 실물 사진이나 다중 제품·프로모션 문구는 없어 지금 구할 수 있는 것 중 가장
  깨끗하다.

## 텍스트 기준 적용 방식 (명확화)

제품 라벨 자체에 인쇄된 제품명·성분 문구(예: "AHA/BHA Clarifying Toner", "Oil Control")는
위반으로 안 쳤다 — 어떤 실제 제품 패키지샷에도 라벨은 항상 있기 때문에, 이걸 위반으로
치면 사용 가능한 사진이 하나도 없어진다. 위반으로 잡은 "텍스트"는 **판매자가 이미지 위에
따로 얹은 홍보 문구·뱃지·할인율·수상 로고** 만이다.

## 반영

- `products.image_url` 12개 UPDATE (`drizzle/seed/scripts/fix_product_thumbnails.mjs`).
- 향후 재실행 시에도 같은 이미지가 들어가도록 원본 삽입 스크립트
  (`insert_cosrx_real_products.mjs`, `insert_roundlab_real_products.mjs`,
  `insert_oliveyoung_kr_product.mjs`, `insert_numbuzin_kr_product.mjs`,
  `insert_beautyofjoseon_anua_products.mjs`)의 `imageUrl` 값도 전부 동일하게 수정.
- 테스트 유저로 `/recommendations`(국내 KR 기본 뷰)와 `?intl=1`(해외 포함) 양쪽 다 실제
  화면에서 12개 전부 재확인 — 깨끗한 단독컷으로 정상 렌더링됨.

## 남은 절충

- COSRX Snail 96 Essence는 100mL(우리가 파는 사이즈)의 깨끗한 단독컷이 갤러리에 없어서
  30mL 여행용 사이즈 사진(라벨 디자인은 동일)을 대신 썼다.
- 넘버즈인은 위에 적은 대로 작은 뱃지 텍스트 2개가 남아있다.
- 두 경우 다 "가장 우선순위 낮은 기준(텍스트)"에서만 완전하진 않고, 단독컷·인물없음·
  다중제품없음의 상위 3개 기준은 전부 만족한다.
