# 여러 사이트로 확장 (Olive Young 브랜드 다양화 + iHerb)

"쿠팡·올리브영은 예시일 뿐, 내가 모르는 수많은 사이트를 찾아서 가져와야 한다"는 요청에
따라, 이미 뚫어둔 올리브영+KCIA 파이프라인으로 **다른 브랜드**를, 그리고 **완전히 다른
사이트**(iHerb, 국제 K뷰티 리셀러)를 추가로 시도했다.

## 추가한 것

- **넘버즈인**(올리브영 경유): "3번 모공제로 화잘먹 패드" — 30개 성분 중 30개 KCIA로
  검증. "변성알코올"→Alcohol Denat.(우리 토너 민감도 규칙과 바로 연결), "향료"→Fragrance
  (기존 Parfum 별칭과 연결)까지 실사용 검증됨.
- **ISNtree**(iHerb 경유, 완전히 다른 사이트): "히알루론산 토너" — iHerb 자체의 상품
  설명은 기계번역 경고문이 붙어 있어 신뢰하지 않았고, 대신 `.prodOverviewIngred`에 있는
  제조사 원본 전성분표(20개)를 썼다. 전부 KCIA로 검증, `country='US'`로 태그
  (PRD상 iHerb는 "해외 채널" 예시로 이미 명시돼 있어 브랜드 국적과 무관하게 그렇게 태그).

## 검증 중 실제로 잡은 오류 하나

"백자작나무(Betula alba)수액"을 처음엔 "자작나무수액"으로 줄여서 검색했더니 KCIA가
"Betula Platyphylla Japonica Juice"(다른 종)로 매칭시켰다. 라벨이 명시한 학명(Betula
alba)과 다른 종이라는 걸 알아채고, "만주자작나무수액"(Betula Alba의 KCIA 표준 한글명)으로
다시 검색해 정확한 매칭("Betula Alba Juice")을 찾았다. 비슷해 보이는 이름으로 대충
넘어가지 않고, 학명이 다르면 다른 성분으로 취급했다.

## 지금까지 실제 제품 총계

COSRX 7개 + Round Lab 5개 + 올리브영(구달 1, 넘버즈인 1) + iHerb(ISNtree 1) = **15개
실제 제품**, 5개 브랜드, 4개 경로(브랜드 공식몰 2곳 + 한국 종합몰 1곳 + 해외 리셀러 1곳).

## 여전히 유효한 제약

지금은 이 대화의 브라우저 세션을 통해서만 동작한다. "수만 개 자동 수집"은 헤드리스
브라우저 인프라가 필요한 별도 아키텍처 결정이며, 지금은 이렇게 세션마다 사이트를 넓혀가며
수동으로 늘리는 것이 현실적인 방법이다.
